# Project_K_001
클로드 AI를 활용 하여 개발 중입니다.
500 vs 500 정도의 대규모 전투를 상정하여 개발 중 입니다.
하루 1~2시간 정도 투자하여 개발 중이며 4월 초 부터 작업을 시작 하였습니다.
케릭터 리소스를 제외한 모든 이미지 및 소스는 클로드 AI를 활요 하여 만들 었습니다.
코드의 90%는 클로드가 작업하였고 전체적인 구조만 제가 잡고 진행 중 입니다.

개발 정도는 약 70% 정도 진행 된 상태입니다.
